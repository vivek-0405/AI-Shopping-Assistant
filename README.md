# GrowthPilot AI — AI Growth & Agentic Commerce Platform

## Overview

GrowthPilot AI is an AI-powered **Growth & Agentic Commerce Platform** designed to help businesses discover products, analyze market trends, understand customer behavior, and make smarter growth decisions using AI.

The platform combines **AI-powered recommendations, product discovery, marketing insights, customer analytics, and agentic workflows** into a single modern dashboard. AI agents can analyze user requirements, recommend suitable products or strategies, and assist users throughout the decision-making process.

GrowthPilot AI provides an intuitive and responsive interface that helps businesses and users turn data into actionable growth opportunities.

## ⚙️ Installation

### 1. Clone the repository

```bash
git clone https://github.com/vivek-0405/GrowthPilot-AI.git
```

### 2. Navigate to the project folder

```bash
cd GrowthPilot-AI
```

### 3. Install dependencies

```bash
npm install
```

### 4. Configure environment variables

Create a `.env` file in the root directory and add your AI API configuration.

```env
VITE_AI_PROVIDER=gemini

VITE_GEMINI_API_KEY=your_gemini_api_key

VITE_OPENAI_API_KEY=your_openai_api_key
```

> Never commit your `.env` file or API keys to GitHub.

## AI Workflow

The GrowthPilot AI workflow follows an agentic approach:

```text
User Input
    ↓
Understand User Intent
    ↓
AI Agent Processing
    ↓
Data / Product Analysis
    ↓
Generate Recommendations
    ↓
Growth Insights
    ↓
Personalized Action Plan
```

### Workflow Steps

1. User enters a product, business requirement, or growth objective.
2. The system analyzes the user's intent and requirements.
3. AI processes the request using a structured prompt.
4. The AI agent analyzes available product, customer, or market information.
5. The system generates personalized recommendations.
6. Growth insights are presented through the dashboard.
7. Users can review recommendations and take appropriate actions.

---

## Agentic Commerce

GrowthPilot AI uses the concept of **Agentic Commerce**, where AI agents assist users with commerce and business decisions instead of simply displaying static information.

For example:

```text
User:
"I want a laptop for coding under ₹70,000."

        ↓

AI Agent

        ↓

Understands:
• Budget
• Product category
• Use case
• Required specifications

        ↓

Analyzes Products

        ↓

Compares Options

        ↓

AI Recommendation

        ↓

Best Products + Reasons + Insights
```

The goal is to move from **search → recommendation → decision assistance** through an AI-driven workflow.
